Qmux is a terminal for coding agents, with first-class support for visual queueing and agent orchestration.

Sequence dozens of tasks for Claude, Codex, Grok, or OpenCode. Multiplex agents to check each others' work.

Features

  • First-class agentsNative support for different coding agents: Codex, Claude, Grok, OpenCode.
  • Vertical splittable tabsThe sidebar shows every terminal and agent, grouped by project. Drag to reorder.
  • Rich text transcriptsYour agent’s transcript renders through a native parser: Markdown, tables, code blocks, graphs.
  • Turn queueQueue up follow-ups while an agent works; edit, reorder, and drag queued work between panes.
  • Automatic recoveryTerminals automatically respawn on restart, along with tab groups, queued turns, and drafts.
  • Session forkingFork a running session to a new tab. The fork inherits the transcript, up to your last turn.
  • Git worktreesLaunch agents into their own worktrees, with dirty-state checks and auto-cleanup on close.
  • Prompt librarySave your commonly used prompts. Insert them from the ⌘K command palette.
  • Based on libghosttyEvery pane is a real libghostty terminal, rendered natively with Metal.

FAQ

What is qmux?

A Mac desktop app, terminal multiplexer, and agent control plane in one.

How is it different from tmux?

tmux runs in your terminal and multiplexes terminals; qmux is a terminal and multiplexes agents. It adds a native GUI and rendering, which a terminal-only multiplexer can’t see into.

How is it different from cmux?

Both are agent-friendly terminals with vertical tabs. cmux is mostly a terminal. qmux is mostly a control plane.

How is it different from Herdr?

Both are agent-friendly terminal multiplexers. qmux is a terminal app, while Herdr runs inside a terminal app.

How is it different from Conductor, T3 Code, etc.?

Those hide the terminal behind a dashboard, and often use Agent SDKs. In qmux you use the native CLIs for your coding agent.

Which agents does it support?

Claude Code, Codex, Grok, OpenCode. Agents are integrated through a pluggable adapter layer, so new ones can be easily added.

How do I launch agents inside qmux?

Run claude or codex in any shell pane and qmux routes it automatically.

How does qmux know what an agent is doing?

Our shell injects hooks for claude, codex, and other agents, that report session start, prompts, tool use, and permission requests over a Unix socket. Hooks are only installed in shells in qmux, not globally.

What platforms does it run on?

macOS 13 (Ventura) or later, either Apple Silicon or Intel. Linux is planned.

Is my data sent anywhere?

No. The application is entirely local and sends no telemetry. Tab title generation uses Apple Foundation Models on your local device by default.

What's the business model?

qmux was created as a part of our research efforts, and is now available as a free and open source project under the MIT License.
